# Script for Automation

Lightweight scripts that automates battles on **DemonicScans** to help complete achievements.

---

## Added Scripts

- Non HUD, PvP Solo Battle script for cleric
- HUD script for first anniversary, manual hunt

---

## Installation

1. Install a userscript manager:
   - **Tampermonkey** (recommended)
   - **Violentmonkey**
   - **Greasemonkey** (Firefox)

2. Create a new userscript.

3. Copy and paste the contents of this script into the editor.

4. Save the script.
